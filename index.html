Identidad y System Prompts

Cada personaje posee su propio avatar, tono, época, restricciones y temperatura. Desde filósofos de la antigüedad hasta asistentes técnicos modernos.

Memoria RAG Vectorial

Fragmentación inteligente (450 chars + 70 overlap) e indexación con embeddings de OpenAI (1536 dimensiones) con búsqueda por similitud de coseno en SQLite.

OpenAI & DeepSeek

Soporte sin fisuras para GPT-4o, GPT-4o-mini y DeepSeek (V3 y R1 Reasoner). Configura y alterna modelos por personaje o globalmente.

SQLite Nativo (Node 24)

Utiliza node:sqlite DatabaseSync en modo WAL con claves foráneas en cascada. Rendimiento ultrarrápido sin requerir servicios externos pesados.

Traza de Representación

Modal visual paso a paso que desglosa la latencia de red, el consumo de tokens y las fuentes RAG exactas utilizadas en cada respuesta.

Mecánica Interna

¿Cómo funciona por dentro con ChatGPT o DeepSeek?

Los LLMs son stateless (sin estado). Cada llamada HTTP es independiente. MBot reconstruye el contexto completo en 6 etapas precisas:

PASO 01

Entrada en SQLite

El mensaje del usuario se inserta de inmediato en la tabla messages de SQLite con su conversation_id.

PASO 02

Memoria Corto Plazo

Se recupera una ventana deslizante de los últimos 16 mensajes para garantizar la coherencia temática sin exceder la ventana de tokens.

PASO 03

Memoria Largo Plazo (RAG)

Si es bot RAG, se vectoriza la consulta con OpenAI (1536 dims) y se calculan similitudes de coseno en SQLite recuperando los mejores fragmentos.

PASO 04

Ensamblado del Payload

Se fusionan el System Prompt (identidad), los fragmentos RAG y el historial en un JSON estructurado listo para la API.

PASO 05

Llamada al Modelo LLM

Despacho HTTP a OpenAI o DeepSeek. Se captura la latencia de red en milisegundos y el consumo exacto de tokens.

PASO 06

Persistencia y Traza

Se guarda la respuesta en SQLite vinculando el contexto utilizado para auditoría e inspección en el modal de Representación.

Model Context Protocol

Servidor MCP Oficial: Crea de Todo

Permite a agentes de IA como Cursor, Claude Desktop o Antigravity controlar el sistema mediante 14 herramientas estandarizadas.

create_bot

Crea bots con identidad, memoria, proveedor y prompt.

list_bots

Lista todos los bots con métricas de documentos y chat.

get_bot / update_bot

Inspecciona y modifica perfiles e instrucciones en vivo.

add_knowledge_document

Auto-divide texto y genera embeddings de OpenAI.

test_semantic_search

Calcula similitud de coseno en tiempo real.

chat_with_bot

Chatea con bots, guarda memoria y devuelve traza.

Configuración en Cursor (.cursor/mcp.json) Listo para usar 
{
  "mcpServers": {
    "mbot-studio": {
      "command": "node",
      "args": ["c:/Users/benja/Desktop/mbot/mcp/server.js"]
    }
  }
}
Para iniciar el servidor MCP independientemente: npm run mcp

Desarrolladores

4 Formas Sencillas de Crear Personajes

1

CLI Interactivo (El más fácil)

Ejecuta el script y responde las preguntas guiadas directamente en tu terminal: 

node scripts/create-bot.js
2

Línea de Comandos Rápida

Pasa todos los parámetros directamente en una sola instrucción: 

node scripts/create-bot.js "Don Quijote" "🛡️" "Caballero" "simple" "deepseek" "deepseek-chat" "Eres Don Quijote..."
3

En JavaScript / Node.js Directo

import { BotService } from './src/services/botService.js';

const bot = BotService.createBot({
  name: 'Nikola Tesla',
  avatar: '⚡',
  role: 'Genio Electricidad',
  type: 'rag',
  provider: 'openai',
  model: 'gpt-4o-mini',
  system_prompt: 'Eres Nikola Tesla...'
});
4

API REST con cURL / Fetch

curl -X POST http://localhost:3000/api/bots \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Marie Curie",
    "avatar": "🧪",
    "type": "simple",
    "provider": "deepseek",
    "system_prompt": "Eres Marie Curie..."
  }'
